# ⚡ Momentum
**Momentum** is a high-performance, privacy-focused daily habit and activity tracker. Built for developers and high-achievers who value data sovereignty and minimalist design.

---

### ✨ Core Features
* **🧠 The "Brutal Coach" Engine:** A custom-weighted algorithm that calculates your daily productivity score (0-100) based on goal completion, consistency, and log volume.
* **🛡️ Privacy-First (AES Encryption):** All user data is encrypted locally using `crypto-js` (AES) before being saved to the browser's storage. Your data never leaves your machine.
* **🎨 Dynamic Theme System:** Switch between four high-contrast professional themes:
    * **Momentum (Purple):** The signature brand look.
    * **Emerald (Green):** High-energy focus.
    * **Cobalt (Deep Blue):** Professional IDE aesthetic.
    * **Titanium (Steel):** Minimalist industrial silver.
* **📱 Mobile-First App Shell:** Optimized for desktop and mobile with "Active-Only" navigation labels and safe-area insets for a native-app feel.

---

### 🛠️ Technical Stack
* **Framework:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Security:** Crypto-JS
